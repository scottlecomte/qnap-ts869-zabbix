# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-08-21

Initial public release.

### Added

- Zabbix 7.4 template for QNAP TS-869 Pro / QTS 4.3.x
- SNMP availability monitoring
- Monitoring for HDD1-HDD8
- Disk model, capacity, health, and temperature
- Empty-bay-safe trigger behavior
- Two system fan RPM items and stopped-fan triggers
- DataVol1 total, free, utilization, and status monitoring
- Four logical CPU utilization items
- Calculated average CPU utilization
- Physical memory, buffers, cache, available, used, and utilization metrics
- CPU, memory, disk-temperature, fan-speed, and volume-utilization graphs
- Configurable alert thresholds through macros
